# 攒攒 功能路线图

日期：2026-07-10 ｜ 状态：活文档（每合入一个切片更新一次） ｜ 上游：[`数据库设计文档.md`](./数据库设计文档.md)（能力全景）、[`superpowers/specs/2026-07-06-architecture-design.md`](./superpowers/specs/2026-07-06-architecture-design.md)（架构）

## 0. 原则

1. **记一笔三秒完成**（数据库文档 §12.3）：能力全 ≠ 入口全。报销、分期、授信池、多币种都是「用到才出现」的渐进披露，默认界面永远极简。
2. **每片合入 main 都可跑可测**：切片沿依赖方向排序（没有账本就没有账户，没有分类就记不了账），不存在半成品状态过夜。
3. **schema 已全量就位**：15 张表 2026-07-06 建齐，后续所有功能都是 Draft/Commands/Provider/UI 切片，**不动 schema**（改 schema 须回数据库文档第 13 章走版本化流程）。
4. UI 全部 iOS 26+ 原生组件，不做自定义 chrome。

## 2. M1 —— 能看、能管（下一个切片）

> 目标：从「能记」到「能看」，补齐日常使用的最后两块。

- **分类管理 UI**：两级分类增删改/归档/排序、「恢复默认分类」（按 `isBuiltIn`）；账本专属分类暂缓（全局分类够用）。（逻辑层已合入：`CategoryDraft`/`CategoryService`/`CategoryTreeProvider` 就绪，待 UI）
- **统计页首版**：月收支汇总 + 分类占比/排行（Swift Charts），二级金额 rollup 汇入父类；月份切换。（逻辑层已合入：`MonthlyStatsProvider` + 统计口径派生就绪，待 UI）
- **明细页打磨**：账本切换器（多账本用户）、日/月小计行、流水筛选（按类型/账户）。（逻辑层已合入：`TransactionListFilter`/`TransactionListGrouping` 就绪，待 UI）

## 3. M2 —— 记账进阶

> 目标：覆盖真实记账的高频进阶场景，入口按需披露。

- **预算**：总预算 + 分类预算（模板行 → 按月实体行），预算已用额投影（含 `isExcludedFromBudget`），预算页进度展示。
- **信用卡**：账户详情页（本期账单/剩余额度投影，按 `statementDay` 切分）、还款（转账语义）、**授信池 UI**（多卡共享额度，成员绑定/解绑）。
- **报销/退款**：垫付标记（waiting/settled）、打款关联（`TransactionLink` M:N 分摊）、统计口径剔除（报销入账不计收入、退款冲减支出）。
- **标签**：流水挂标签 + 按标签筛选。
- **余额校准**：「校准到实际余额」命令（`adjustment` 流水），理财账户市值更新走同一入口。

## 4. M3 —— 自动化

- **周期记账**：`RecurringRule`（房租/工资类模板流水），到期生成 + 补记。
- **分期/贷款**：计划 + 期数表 UI，一期一笔转账（amount=本金、fee=利息），提前结清。
- **维护命令**：余额快照（`BalanceSnapshot`）生成与全量重算一致性入口。

## 5. M4 —— 数据与同步

- **多币种**：解锁非 CNY 账户/流水（`fxRateToBase` 快照预填、跨币种转账到账金额），当前 MVP 锁 CNY。
- **CSV 导入/导出**：`TransactionCSVImporter/Exporter`，导入批次整批撤销。
- **CloudKit 开启**：`.none` → 私有库；开启前必须完成——Decimal（`fxRateToBase`）映射验证、`initializeCloudKitSchema` 15 表红线校验、多设备默认账本归一化实测。
- **附件**：流水票据照片（沙盒 `Attachments/`，孤儿清理维护命令）。

## 6. 远期（数据库文档 §11 占位，立项再动）

全量备份/恢复（JSON 14 表）、语音/OCR 记账与识别日志表、汇率 API 自动刷新、年/周预算、存钱计划、家庭共享/多人账本、商家维度统计、`feeCategoryID` 自定义利息归属、macOS destination。

## 7. 刻意不做

- 自定义主题/皮肤系统（原生外观即设计语言）。
- 广告、会员、云端账号体系（本地 + iCloud 私有库，数据属于用户）。
- 资产分组表（授信池是业务实体不是分组，见数据库文档裁决 8）。
- 流水级「不计入资产」豁免（只允许账户级 `isIncludedInNetWorth`，裁决 14）。
