# 攒攒 功能路线图

日期：2026-07-30 ｜ 状态：活文档（每合入一个切片更新一次） ｜ 上游：[`数据库设计文档.md`](./数据库设计文档.md)（能力全景）、[`superpowers/specs/2026-07-06-architecture-design.md`](./superpowers/specs/2026-07-06-architecture-design.md)（架构）

## 0. 原则

1. **记一笔三秒完成**（数据库文档 §12.3）：能力全 ≠ 入口全。报销、分期、授信池、多币种都是「用到才出现」的渐进披露，默认界面永远极简。
2. **每片合入 main 都可跑可测**：切片沿依赖方向排序（没有账本就没有账户，没有分类就记不了账），不存在半成品状态过夜。
3. **schema 已全量就位**：15 张表保持不变；2026-07-27 以 SchemaV2 为分期规则补齐字段并提供 V1→V2 lightweight migration。后续改 schema 仍须回数据库文档第 13 章走版本化流程。
4. UI 全部使用 iOS 26+ 原生组件与 Liquid Glass，允许品牌化色彩、间距和信息层级调整，不自造一套控件系统。

## 2. M1 —— 能看、能管（已交付）

> 目标：从「能记」到「能看」，补齐日常使用的最后两块。

- **分类管理 UI**：两级分类增删改/归档、「恢复默认分类」（按 `isBuiltIn`）已接通。
- **统计页首版**：月收支汇总 + 分类占比/排行（Swift Charts），二级金额 rollup 汇入父类及月份切换已接通。
- **明细页打磨**：账本切换器、日/月小计、类型/账户/标签筛选已接通。

## 3. M2 —— 记账进阶（已交付）

> 目标：覆盖真实记账的高频进阶场景，入口按需披露。

- **预算**：总预算 + 分类预算（模板行 → 按月实体行）、预算独立排除口径及进度页已接通。
- **信用卡**：账户详情、本期账单/剩余额度、还款与多卡共享授信池已接通。
- **报销/退款**：垫付状态、M:N 分摊、到账/退款及统计冲减已接通。
- **标签**：标签管理、流水挂标签与按标签筛选已接通。
- **余额校准**：按历史时点生成 `adjustment` 流水，理财估值走同一入口。

## 4. M3 —— 周期自动化与分期基础（已交付范围）

- **周期记账**：`RecurringRule`（房租/工资类模板流水），到期生成、补记、暂停及恢复已接通。
- **分期/贷款**：计划 + 期数表 UI，用户确认后一期一笔转账（amount=本金、fee=息费），支持提前结清、先息后本纯息期、取整/余数规则、息费收取方式与银行产品预设。`isAutoSettle` 当前为必须保持 false 的保留字段。
- **维护命令**：余额快照（`BalanceSnapshot`）生成、失效与全量重算，以及报销/退款到账冗余标记的全量重建入口已接通。

## 5. M4 —— 数据与同步（本地功能已交付，CloudKit 待开启）

- **多币种**：非 CNY 账户/流水、`fxRateToBase` 快照预填、跨币种转账到账金额与三套折算口径已接通；外部汇率 API 仍待接入。
- **CSV 导入/导出**：整批原子导入、内容哈希重复检测、批次撤销/恢复及带跳过披露的普通流水导出已接通；单文件限 32 MiB、10,000 条数据行。
- **完整备份/恢复**：原生目录包 `.zanzanbackup` 已接通，覆盖 14 张非 `AppMeta` 表、`schemaVersion` 与全部引用附件；恢复会精确覆盖当前数据，覆盖前自动生成恢复前安全备份，App 启动时自动收敛中断状态。
- **CloudKit 开启**：`.none` → 私有库；开启前必须完成——Decimal（`fxRateToBase`）映射验证、`initializeCloudKitSchema` 15 表红线校验、多设备默认账本归一化实测。
- **附件**：流水票据照片、沙盒 `Attachments/` 存取删与孤儿清理入口已接通；写入与完整备份共用 10,000 个、单个 128 MiB、合计 256 MiB 上限。

## 6. 远期（数据库文档 §11 立项备查）

- **分期后续能力**：到期提醒与自动结算（先确定并持久化还款来源账户）、待还期逐期改期/减免、浮动利率重定价及 `AuditLog`。在对应命令、UI 与测试完成前不得标记已交付。
- **其他远期能力**：语音/OCR 记账与识别日志表、汇率 API 自动刷新、年/周预算、存钱计划、家庭共享/多人账本、商家维度统计、`feeCategoryID` 自定义利息归属、macOS destination。

## 7. 刻意不做

- 任意图片皮肤、字体包和破坏系统可访问性的全局外观替换；品牌主题仅调整语义色与原生玻璃层级。
- 广告、会员、云端账号体系（本地 + iCloud 私有库，数据属于用户）。
- 资产分组表（授信池是业务实体不是分组，见数据库文档裁决 8）。
- 流水级「不计入资产」豁免（只允许账户级 `isIncludedInNetWorth`，裁决 14）。

## 8. 维护约定

- 每个切片合入 main 后：把该项从对应里程碑挪进 §1 已交付表格，一行写清交付内容。
- 里程碑内条目按依赖排序，但**不承诺日期**；调整优先级直接改本文档并在 commit message 说明理由。
- 新功能想法先落 §6 远期或 §7 刻意不做，不直接插队进 M1–M4。
